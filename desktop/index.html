                Sync saved posts, which posts All has shown, and the All feed itself with Royal on iOS and in other browsers, through your private iCloud database. Optional: without it, Royal keeps everything in this browser.

                iCloud

                Sign in with the Apple Account on your iPhone and Royal syncs; sign out and it stops. Apple handles the login. On iOS, turn on Settings › Sync with Desktop with the same Apple Account. iOS syncs saved posts and seen posts; the All feed itself syncs between browsers.

                Not signed in.

                Signing in adds this browser’s library to the Apple Account without overwriting anything already there. Signing out goes back to this browser’s own library; each Apple Account’s copy stays here for its next sign-in. Sign out on a shared computer.

                Connection troubleshooting

                This checks extension host access and CloudKit reachability with an invalid test token. It does not change your sign-in session.

                Apple’s sign-in returns to (extension origin ); the CloudKit web API token’s redirect URL must match it.

                For a browser network error, open this extension’s Details in the browser’s extensions page, inspect its service worker, then retry Sign in. Note the browser error code; request addresses can contain tokens, so do not share full URLs.
